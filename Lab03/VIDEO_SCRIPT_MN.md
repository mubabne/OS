# 1 минутын бичлэгийн төлөвлөгөө

Бичлэгийг өөрийн дуу хоолойгоор хийнэ.

1. `programs` хавтас болон эх кодуудыг 5 секунд харуул.
2. `make` ажиллуулж C програмууд алдаагүй хөрвөж байгааг харуул.
3. `./collatz_fork 35` ажиллуулаад child process дараалал гаргаж, parent нь `wait()` ашиглан хүлээж байгааг тайлбарла.
4. `./reverse_case_pipes "Hi There"` ажиллуулаад хоёр pipe ашиглан parent-child хооронд мессеж хоёр чиглэлд дамжсаныг тайлбарла.
5. `./time_pipe ls` ажиллуулаад эхлэх цагийг pipe-аар дамжуулж, нийт хугацааг parent тооцсоныг хэл.
6. Тайлангийн PDF-д 3.1-3.7-ийн асуулт, хариулт монголоор орсныг харуулаад дуусга.

Ярих жишээ: “Энэ лабораторид fork, wait, pipe, shared memory ашигласан. Collatz програм child process дээр дарааллыг бодож, parent процесс дуусахыг нь хүлээнэ. Reverse-case програм хоёр pipe-аар мессежийг хоёр чиглэлд дамжуулдаг. Time програм командын эхлэх цагийг IPC ашиглан parent-д өгч, гүйцэтгэлийн хугацааг тооцдог.”
